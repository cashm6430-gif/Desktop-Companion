# 坐姿关键形增强 r1 — 设计卡（pending 用户审批，2026-10-07）

状态：**关键姿势概念审批中**。上位：批次 3/坐姿三修复/五官跑位修复之后；
按「先审关键姿势再绑定」流程，批准后才进入 PSD2Live 制作与绑定。

## 1. 目标与趣味点

坐下/起身全程可见（七相位：SitDown 0.7s / ExitReveal / SitUp 0.55s），
当前过渡只有「站姿形 → 坐姿形」两端的材质切换，中段没有身体中段的过渡形。
本轮补两处关键形，让可见过程有体积感：

1. **ParamSkirtSpread（裙撑）**：裙摆自臀部向两侧摊开、下缘压向贴地线，
   让 SitDown 过程中裙子有「被腿撑开摊下」的过程，而非瞬间切换。
2. **ParamHandGround（撑地手）**：坐姿可见时右臂（画面左侧）斜撑地面，
   掌心贴地；上桌工作模式（桌/键盘在场）该手自然不显示。

## 2. 最低成本方案（复用优先）

- **撑手**：复用 `layers/01-handwear-l.png`（袖口+自然下垂的手）旋转重摆 +
  `12-upperarm-l.png` 袖管，PSD2Live `insert_meshes` 新网格（新页）。
  肩部衔接处预计需一小块补绘（正式制作时做）。渲染层序：手在裙摆外侧、
  躯干之后；透明度由 sitDrive 驱动（坐稳后淡入，起身反向）。
- **裙撑**：`mesh_grids` 给既有 `busy skirt` 网格加 keyform 通道，
  0=现行形态，1=摊开贴地形。纯网格形变，无新贴图；由 sitDrive 驱动
  过渡，不新增开关。若大形变后裙下缘露出腿根，再补裙内侧暗部（二阶段）。
- **不动**：头/颈链路、贴地契约、桌管线、双材质互斥、authoredSitPose 预留路径。

## 3. 关键拍（附图 phase2-keypose-brief.png）

- 红链 = 肩→肘→掌（肩点正式制作时按 Native 帧校准，被发束遮挡处从简）
- 半透明袖口手 = 素材复用摆位示意（01-handwear-l 旋转 ~25°）
- 红折线 = 裙摆摊开后的下缘目标（现行下缘已接近，形变重点在过渡中段）

## 4. 风险

- 袖口↔肩部衔接穿帮 → 小补绘兜底
- 裙形变带动蝴蝶结/装饰变形 → 网格分片控制形变权重
- 坐姿窗口 280px 下掌心细节不可辨 → 形以剪影为主，不追求指缝
