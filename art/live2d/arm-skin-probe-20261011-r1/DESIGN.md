# 2D 手臂蒙皮探针（R1，2026-10-11）

**问题**：模型里的手臂读作僵硬，超过约 60° 后读作一根细而歪的棍子。两种解释都在桌上——
①这套分层根本不支持抬臂；②分层没问题，是绑定错了。

**答案：②。** 分层是够的：

- `topwear` 在 `y≥598` 处**本来就裂成三块**（左袖 `x450-528` / 躯干 `536-718` / 右袖 `x>730`），
  所以"切出袖子"是**掩码操作、不是补画**（袖块 3312px = 上衣 8.5%）；
- `arm-backing` 是**两侧长发**（名字意为"手臂位置的底衬"），它连躯干都不含（行跨度中间是空的），
  原作者**已经为抬臂预留了底衬** —— 所以不露白、不需要补画关节。

问题在**变换**。本目录是把它修好的证据。

python tools/probe_arm_skin.py

python tools/probe_arm_skin.py --out art/live2d/arm-skin-probe-20261011-r1

## 门（`RIG_RESULT PASS`）

| 门 | 声称 | 实测 |
|---|---|---|
| RIGa | 面积/质量守恒，新版本在 rest 的 ±10% 内 | **1.054 / 1.061 / 1.031** |
| RIGb | 切缝两侧**相邻像素**权重连续（<0.10 个"完整拉动"） | **0.03133（竖切）/ 0.01791（横切）** |
| RIGc | 臂板内部不出现新的空洞 | **+0 px**（rest 与 −70 都是 0） |

RIGa 的 +3~6% 盈余来自 1.45px 面积足迹轻微越过单位覆盖 —— 这是"不留空洞"的代价，已知。
RIGb 的参照尺度：如果权重是**按图层**而不是按**画布位置**给的，这条缝上的相邻像素会差 **~1.0**。

## 七个版本，五个失败

`warp_lbs` 的 docstring 里逐条记着，因为这些都是 2D 蒙皮的通用陷阱：

1. **逆映射 + 连续权重场**：`R·dθ/ds>1` 处折叠；更关键的是**径向**场的梯度**横穿**肢体，
   袖子两条边最终转差 **~31°** → 在关节处被**剪切变细**。**这就是用户看到的"细"。**
2. **逆映射 + 输出空间权重**：域不动、内容动 → 摆过去的像素被交还给恒等 → 肢体被身后内容覆盖。
3. **正向 splat，每段一份拷贝**：质量精确、无孔（每份拷贝都是等距变换），但一个像素被写到它所
   属段的每一个位置 → **从关节放射的重影条纹**。
4. **正向 splat + 每像素一个加权平均目标 + 点核**：正确，但相邻目标可能相隔 >1px →
   **半透明点阵**。单位和的核救不了它——单位和的核正是留孔的原因。
5. **同 4 + 1.45×1.45 面积足迹**：alpha 实心（255 占 99%）、点阵消失，但深蓝/白边留下**细密斜向梳齿**。
6. **不动点迭代求逆映射**：需要位移场单射才有解，非单射处迭代发散成拉伸。
7. **正向 LBS + cubic B 样条分段混合 + 1.45 面积足迹 + 2× 超采样** ← 采用。

第 5 版的梳齿是**走样不是覆盖**：正向映射让目标采样位置不规则，拉伸区里每个目标像素只抽到少数
相位锁定的源像素，边界与采样格拍频。**加宽核只会把拍频糊掉**；要**采样得比走样更细**才行。

## 一次口径更正（重要）

早期笔记里写"逆映射折叠丢像素 ⇒ 面积掉到 **47%**，这就是变细"，并把它立成判据。**这是错的**：

- 干净的逆映射 + 连续场在 **r=70..300、46°/70° 下质量守恒 100.0%**（本次实测两行）；
- 正向 LBS 是 104–107%；
- 那个 47%（以及 49%、61%）来自**把两种口径不同的合成方式拿来相比**（逐板并集 vs 单张合成），
  叠加当时的窗口 bug，**今日不可复现，撤回**。

**真正区分好坏的是权重场的几何**：梯度是否**沿肢体**（径向场横穿 ⇒ 剪切），以及权重是否是
**画布位置的函数**（图层作用域 ⇒ 切缝张开）。**折叠条件 `R·dθ/ds ≤ 1` 仍然有效**，且
**band 越窄越容易折叠** —— "把肩部过渡带收窄让手臂更硬"是反向的。

## 交付参数（给 Live2D 绑定用）

| 量 | 值 |
|---|---|
| 关节 | 臂轴与切缝 `y=598` 的交点 **(533, 598)** |
| 臂轴 | 由左臂三层并集 ink 中线拟合 **(−0.478, +0.879)** |
| 过渡带 `band` | 臂纵向距离的 **0.75 分位 ×1.1 = 123.9px** |
| 横向衰减 | **R0=60 / R1=140**（臂内 `perp≤48` ⇒ 无梯度、不剪切） |
| 分段 | 14px，cubic B 样条（C2）混合 |
| 足迹 / 超采样 | 1.45px / 2× |

取满袖子全长当 band 会把整条袖子放进渐变，手臂只转出约 70% 的角度、看着"没抬起来"。
